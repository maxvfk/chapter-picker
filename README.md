# EPUB Chapter Picker

Мобильная PWA для локального разбора EPUB и копирования одной главы в буфер перед переводом в ChatGPT.

## Возможности

- EPUB 3 `nav.xhtml`;
- EPUB 2 `toc.ncx`;
- fallback по `spine` из OPF;
- вся обработка EPUB выполняется локально в браузере;
- книга и текущая глава сохраняются локально;
- `Скопировать главу`;
- `Скопировать + prompt`;
- редактируемый короткий prompt;
- `Скопировать и перейти дальше`;
- предпросмотр, счётчик символов и приблизительная оценка English tokens;
- предупреждение для очень больших разделов;
- PWA/offline после первой загрузки.

Prompt по умолчанию:

> Переведи следующую главу, сохраняя установленный стиль и терминологию.

## GitHub Pages

Приложение статическое и не требует сборки.

1. `Settings → Pages`
2. `Source → Deploy from a branch`
3. Branch: `main`
4. Folder: `/(root)`
5. `Save`

После публикации адрес проекта будет обычно:

`https://maxvfk.github.io/chapter-picker/`

> GitHub Pages публикуется публично даже для private repository, если тариф GitHub поддерживает Pages для private repositories.

## Privacy

EPUB не отправляется на сервер приложения. Файл разбирается локально средствами браузера.
